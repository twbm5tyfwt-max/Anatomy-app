# Study data coverage

All 246 source-classified bone parts have introductory landmark, articulation and representative attachment text guides. These guides are not a complete attachment map for each subregion. The source atlas also has 548 displayed original annotation endpoints that pass the assigned-object bounds check; one misplaced source annotation is excluded. Only explicitly curated landmarks enter graded quizzes.

1,393 attributed archived anatomy readings link to 2,434 source parts and 270 source landmarks. Uberon supplies 799 distinct definitions linked to 1,240 parts across the source atlases; these counts overlap the readings and are not additive. Source surface regions can share a parent structure description.

Missing detailed attachments/innervation remain identified in the app; no attachment point is invented from a name, a silhouette, or an uploaded image. Source figures, comparative lymph-node models and nonhuman specimens retain their captions. Model names and source ancestry remain available for every selectable item. Clinical statements are not inferred from an anatomical reference or OCR result.

Display-material names are not histological diagnoses. The application corrects 39 source metadata records (33 additional layer changes): cardiac valve leaflets, dural folds, eyelid tarsal plates and gelatinous nucleus pulposus are not cartilage. The original geometry and IDs are retained. Teeth remain in the source skeletal display group but are identified as teeth; no compact-bone histology is assigned to enamel/dentin. A dedicated dental micrograph is not bundled.
