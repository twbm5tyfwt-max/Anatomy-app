# Anatomy + PT/AT implementation checklist

User requirements are in the uploaded specification. This file distinguishes working features from asset and verification limits; a licensed asset is not automatically a complete or clinically validated atlas.

| Requirement | Implemented | Remaining / limits |
| --- | --- | --- |
| 1. Consistent selection | Structure clicks no longer depend on a mode. Temporary hover, persistent selection, empty-space clearing, drag/pinch suppression, touch taps, overlap chooser, hidden-surface exclusion, opacity policy, and node hit tolerance. Reset clears old selection/labels/search and restores scope. | Browser acceptance results are recorded in delivery/VALIDATION.md. |
| 2. Presentation | Actual scene gradients: graphite, ivory, midnight; anatomical view names and beginner tooltips. Depth-tested transparency retained; close-up shading limited to small views for performance. | Hardware and model complexity affect frame rate. |
| 3. Anatomy | Pure bony default/skull isolation removes soft nasal cartilage from the bare skull; no cosmetic bone reshaping. Abdominal muscle components and their aponeurotic regions are separately selectable. Linea alba and valve tissue classifications corrected. | Source bone tessellation preserved. No new high-detail muscle fiber or seamless skin asset is available; visible source seams remain. No claim that lighting corrects inaccurate anatomy. |
| 4. Lymphatic | Node/group names, group-versus-node explanation, contextual overview, region filtering, invisible 8 px hit tolerance with occlusion checking. | Fine continuous lymphatic vessels are not modeled; a node group is not subdivided into invented individual nodes. |
| 5. Organs | Source heart components/chambers/available leaflets and connected structures can be isolated/hidden. Prepared four-chamber teaching section is distinctly schematic. Native lung lobes and bronchi plus linked bronchus-to-alveolus magnified teaching guide. | Source cardiac interiors and septal segmentation are incomplete/unvalidated. No arbitrary mesh cut is presented as a true anatomical cross-section. Alveoli/bronchioles are diagrams, not individual 3D objects. |
| 6. Knee/cartilage | Right knee includes menisci, articular surfaces, major ligaments, extensor tissues. Staged removal, source component list, optional displaced exploded teaching view. Tissue links distinguish hyaline/fibrocartilage/elastic cartilage. | Exploded positions are pedagogical offsets, not physiological positions or a scaled biomechanical simulation. |
| 7. Isolation | Skull, face/neck, neck muscles, shoulder, spine, pelvis, knee, abdomen, heart, lungs and lymphatic regions; tissue combinations; framed return to own body/scope. | Region catalog includes only source-derived anatomy. |
| 8. Tissue flow | Structure → tissue overlay; microscope-reference plates, illustrations, zoom, comparison and features. Main camera/selection stay mounted behind the overlay. Existing tissue library gains microscopy references. | Photo plates retain embedded labels and specimen captions, including the dog cartilage example. They are not inferred patient histology and are not used as unlabeled photo quizzes. |
| 9. Study models | + beside Body/Explore, locally extracted PDF/PPTX/text or image transcription, source references, explicit side/component confirmation, manual edits, naming/saving/deletion, independent scope/layers/camera/selection. Scoped quizzes/games. | No OCR/AI service. Scanned pages/images need transcription. Matching cannot understand every term or verify note accuracy; unsupported passages are flagged, never converted to fabricated geometry. |
| 10. Model options | Reference model identity separate from gender; visible status for unavailable female model. | **Blocked by missing complete, accurately licensed female source asset.** No silhouette swap or male anatomy relabeled as a female model. Source audit corrected a previous README claim that female organs were bundled; they are absent. |
| 11. PT/AT | Regional anatomy/injury concepts, overlapping healing stages, general goals, mobility/strength/balance/function examples, precautions, regressions/progressions and source links. Educational boundaries and review status visible. | **Live AAOS/NHS source retrieval blocked by network policy (HTTP tunnel 403).** Latest clinical revision dates/current guideline conformance not verified. No reproduced exercise videos, invented video URLs, individualized protocols, or healing promises. |
| 12. Games | Name/function matching, memory pairs, tissue diagrams, find-and-click, regional/system/confirmed-collection filters, difficulty and timer/untimed settings, feedback/mistakes/history. Labels hidden. Find targets checked by source-surface raycasts; loading/occlusion/rotation/feedback pause timing. | Source-specific function questions require reviewed overview/detail notes. Repeated generic parent-function prompts are not used as ambiguous collection questions. |
| 13. Tutorial | Help launches a skippable, replayable contextual tour attached to actual controls; dismissible invitation. | No mandatory onboarding or forced tour. |
| Licenses (follow-up request) | User selected **noncommercial educational** website/app use. Original credits/license statements, source URLs, figure captions/specimens, checksums, modification notes, software notices, machine-readable asset manifest, and in-app license summary included. | Attribution does not remove noncommercial or share-alike restrictions. No proprietary Complete Anatomy content. Commercial redistribution would need a separate asset/content audit and replacements. |

Existing result/bookmark/course-card/local-file storage keys are retained. New collections, camera/settings, games and tutorial status use separate keys. Browser data remains local; clearing it removes saved work. No server upload or AI processing is introduced.
