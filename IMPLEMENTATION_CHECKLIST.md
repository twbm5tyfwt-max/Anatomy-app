# Anatomy + PT/AT implementation checklist

User requirements are in the uploaded specification. This file distinguishes working features from asset and verification limits; a licensed asset is not automatically a complete or clinically validated atlas.

| Requirement | Implemented | Remaining / limits |
| --- | --- | --- |
| 1. Consistent selection | One pointer interaction; click/tap now isolates with a slow camera close-up by default. Hover remains temporary; empty space clears selection; drag/pinch suppression, transparent-hit policy, reset, overlap chooser and touch remain. Contextual landmark/whole-muscle checkboxes replace selection modes. | Landmark-label checkboxes are disabled when no mapped source points exist; text guides remain available. See validation results. |
| 2. Presentation | Actual scene gradients: graphite, ivory, midnight; anatomical view names and beginner tooltips. Depth-tested transparency retained; close-up shading limited to small views for performance. | Hardware and model complexity affect frame rate. |
| 3. Anatomy | Original bone/joint tessellation retained. Nasal cartilage stays separate from the bony skull. Abdominal layers and source fascia/aponeuroses remain distinct. All 246 source-classified bone parts have landmark, joint and representative attachment guides; 1,393 attributed readings link to 2,434 source parts. 548 of 549 original annotation endpoints pass coordinate checks; one misplaced source marker is excluded. | Source names/coordinates do not establish complete clinical validation. Full point-mapped attachments/innervation and muscle fiber textures remain incomplete. Male skin keeps source seams; the separate HRA source has a body surface, not modeled skin thickness. |
| 4. Lymphatic | Named/selectable source nodes/groups, node hit tolerance, body/tissue links. Added a dedicated component-based lymph-node reference with capsule removal and internal compartments. | HRA Ce3D node uses mouse data; it is visibly labeled as comparative and excluded from the general body scope. Fine continuous human lymphatic vessels are incomplete. |
| 5. Organs | Dissect organ button opens source components and section references. Free HRA heart includes chambers, septum, valves, papillary muscles and vessels with removable walls. Lung/lobe grouping, bronchial-tree reveal, and linked bronchiole → duct → sac → alveolus guide. Kidney and lymph-node component removal; individual show/hide/restore throughout. Published 2D organ sections cover additional organs. | Component removal is not a new validated cut plane. Some organs have only surface geometry; they say so and offer available labeled source sections. Chordae, fine microanatomy and every interior are not fully modeled. |
| 6. Knee/cartilage | Real source bones, articular tissue regions, menisci, ligaments and tendons are selectable in 3D. Display-material misclassifications are corrected for valves, dural folds, eyelid plates and nucleus pulposus; teeth are distinct from bone tissue. Dedicated tissue checkboxes, staged cover removal and optional exploded view. On-model hyaline/fibrocartilage/elastic-cartilage examples link to the tissue library. | Exploded positions are labeled displaced/not to scale. Some articular cartilage is a source-classified surface region, not a full thickness tissue volume. |
| 7. Isolation | Skull, face/neck, neck muscles, shoulder, spine, pelvis, knee, abdomen, heart, lungs and lymphatic regions; tissue combinations; framed return to own body/scope. | Region catalog includes only source-derived anatomy. |
| 8. Tissue flow | Body → structure → tissue overlay retains the body camera/selection. Tissue tab offers published microscopy, diagrams, zoom, labels where separable and comparison. Added context-specific alveolar, columnar, epidermal and renal plates. Modern source-based 2D atlas adds high-resolution section plates and 3D search; previous interactive overview remains available. | Published image labels are embedded. Animal/mixed-tissue specimens retain captions. Missing matched microscopy is stated and a diagram is shown instead of an unrelated specimen. |
| 9. Study models | + creates a guide and linked model from pictures, PDFs, slides or notes. Bundled local English OCR reads image labels and up to 20 scanned PDF pages. Review/correct matches, sides and components; manual edits; original-image preview; written guide with cited structure data, personal notes, learned checks and downloadable/printable HTML. Independent model camera/layers/scope and scoped quizzes/games. | OCR is not anatomical recognition or hidden-geometry reconstruction. Unlabeled, rotated or handwritten images may need manual transcription/topic identification. Uploaded text is not automatically medically verified. Data stays in localStorage/IndexedDB; no recognition API. |
| 10. Model options | Male source atlas plus free HRA female organ-reference assembly, including female reproductive anatomy and body surface. Source identity is separate from gender. Region is preserved when represented; main model state remains available. | Female organ-reference coverage differs from the broader male musculoskeletal source. It is not a complete female muscle/bone atlas or a male silhouette swap. Missing regions are not fabricated. |
| 11. PT/AT | Existing tab improved in place: regional anatomy previews with direct structure links, injury/goals/assessment concepts, overlapping healing stages, purpose filters and technique-first exercise cards with precautions/variations and related clinical instruction links. Anatomy education stays separate from individual care. | Live AAOS/NHS requests remain blocked by environment network policy (HTTP tunnel 403). Current external revisions/guideline conformance remain unverified and are explicitly disclosed; no unlicensed video or personalized plan is generated. |
| 12. Games | Region/collection selection followed by an explicit bone/muscle/connective/organ checklist. Checked IDs define the session; untimed default, optional timer, feedback, missed review and history. No silent difficulty truncation; up to 24 structures (8 memory). Visibility proof and loading/rotation/feedback/hidden-page pauses retained. | Function prompts require supported functional summaries; a reference definition alone does not make a reviewed function question. |
| 13. Tutorial | Existing Help launches a skippable/replayable contextual tour updated for click isolation, checkboxes, source organ components, image guides, scoped checklists and PT resources. | Published illustrations and 3D data remain distinguished. |
| 14. Acceptance checks | 44 unit tests and 36 distinct browser workflows passed, with final targeted repeats for knee defaults, source organ components, local image OCR, guides, scope and saved state. Self-contained HTML passed 10 upgrade workflows over HTTP. See delivery/VALIDATION.md. | Browser tests do not establish clinical accuracy of every source annotation. Direct file:// navigation is blocked by the test environment administrator policy. |
| Licenses (follow-up request) | User selected **noncommercial educational** website/app use. Original credits/license statements, source URLs, figure captions/specimens, checksums, modification notes, software notices, machine-readable asset manifest, and in-app license summary included. | Attribution does not remove noncommercial or share-alike restrictions. No proprietary Complete Anatomy content. Commercial redistribution would need a separate asset/content audit and replacements. |

Existing result/bookmark/course-card/local-file storage keys are retained. New collections, camera/settings, games and tutorial status use separate keys. Browser data remains local; clearing it removes saved work. No server upload or AI processing is introduced.

Follow-up changes preserve the existing navigation, appearance controls, course materials, bookmarks, quiz/progress keys and the original interactive 2D overview. New source assets and guide data use separate identifiers/keys. Detailed inventory: STUDY_DATA_COVERAGE.md. Verification evidence: delivery/VALIDATION.md.

## Follow-up round: simplification and polish (2026-10-20)

Requested changes after reviewing the app: PT/AT "sucks", games are over-complicated and should let you pick sections then tick a checklist, add a ligament toggle on the side, the 2D model is poor, study models could not make a guide/model from pictures, and a cleaner product overall.

| Request | Done | Verified by | Remaining / limits |
| --- | --- | --- | --- |
| **PT/AT rebuilt** | Seven regions (knee, shoulder, ankle & foot, hip & thigh, low back, neck), each with a 3D preview of the real structures, common injuries with involved structures and "when to be assessed" lists, healing stages by tissue type, 28 exercise examples (target, purpose, technique steps, common mistakes, precautions, easier/harder levels, source), a "why treatments are used" section, a muscle/injury/exercise finder, and a Sources tab. No doses, no personalised plans, no healing promises. | `src/studyMatch.test.ts` (content integrity, citations declared, no dose/guarantee wording); screenshots. | **Source review dates are not verified.** The build environment cannot open aaos.org/nhs.uk, so each link is marked "not live-checked". The content date (2026-10-20) is shown. **No exercise videos are embedded:** none are licensed or invented; each exercise links to the cited education page. Needs clinician review before any commercial release. |
| **Games: pick → tick → play** | One page, three steps: choose a region or your collection, tick bones/muscles/ligaments/tendons/cartilage/other (per-group Select all/None, search, quick picks such as "Knee ligaments"), then choose one of five games and Untimed/60 s/120 s. Start is disabled until the selection is valid. Limits raised to 40 structures (10 for memory). | Browser test (select quick pick, start find-and-click); unit test of groups. | Game engine itself is unchanged: timer pauses during loading/rotation/feedback. |

| **2D atlas** | New flat "Atlas plate" drawn from the same source model: anterior/posterior/left/right views, layer chips, labels with leader lines, search, info panel, hide/restore, pan/zoom. | **Study models from pictures** | Review step rewritten: exact matches pre-confirmed, ambiguous ones (side, head, shorthand, misread words) flagged with All / Right only / Left only / None, "Add every suggestion", a no-text "pick by region" builder, shorthand such as ACL/MCL/quads/rotator cuff, tolerance for OCR slips, image upscale + contrast before local OCR, and a clear message when a picture has no readable labels. Saving with unconfirmed suggestions is blocked so a model is never silently empty. Study guide is now collapsible with progress and filters (was an 18,000 px wall). | Browser test with a low-contrast image (OCR 94%, 10 terms found); unit tests for aliases/fuzzy. | A picture is never turned into 3D geometry; unlabeled or handwritten images need typed names or the region picker. Nothing leaves the browser. |
| **Cleaner product / tutorial** | Tutorial copy updated for the new games, ligament row and PT sections. | - | See COMMERCIAL_READINESS.md. |

Browser suites were updated for the replaced UI and run with software WebGL (timeouts raised to 30 s).

## Round 4: the Study tab (2026-10-20)

All seven approved study ideas live in a new **Study** tab (Today · Flashcards · Weak spots · Muscle tables · Worksheets · Backup).

| Idea | Done | Verified by | Remaining / limits |
| --- | --- | --- | --- |
| Backup and restore | One JSON file with everything saved in the browser (study tabs, notes, review deck, practice exams, quiz/game history, goals, appearance) plus optionally the uploaded pictures/documents. Restore either adds only what is missing or replaces matching items; the file is validated first and nothing is sent anywhere. | Browser test: download, delete data, restore, study tab is back. | A backup is a file you must keep yourself; there is no cloud sync. Very large uploads make large files. |
| Review today (spaced repetition) | Leitner schedule (today, 1, 3, 7, 14, 30, 60 days). Cards come from study-tab flashcards, course cards, and automatically from questions and games you missed. Again/Hard/Good/Easy; Again returns the card later in the same session. | Unit tests for scheduling; browser test. | The intervals are a standard teaching schedule, not individually tuned. |
| Daily goal, streak, exam countdown | Goal ring, 7-day strip, streak, exam name/date, countdown and the cards-per-day pace to cover your not-yet-known cards. Quizzes, games, landmark games and card reviews count. | Unit tests (streaks, dates); browser test (persists across reload). | Only activity logged from now on is counted. |
| Flashcards from a study tab | A **Flashcards** button on every study tab, and a picker in Study. Front: the structure coloured among its neighbours (or a landmark dot on its bone); back: name, function, location, and origin/insertion/nerve for muscles. | Browser test and screenshots. | Landmark cards exist only for bones with mapped points (~50). |
| Weak spots | Accuracy by region, a most-missed list (quizzes and games), and buttons to review them or quiz on them. | Browser test with seeded history. | Games record only misses, so game-only items show a miss count without a percentage. |
| Muscle tables and OIAN quiz | Searchable table of the muscles that have a reviewed origin, insertion and action (nerve for about a third), with column covering for self-test, and a quiz in both directions. Rows whose text names the other limb (hand vs foot) are dropped rather than taught. | Unit tests (rows, unambiguous options); browser test. | Only muscles with reviewed entries appear; missing nerves are shown as "not in dataset". |
| Printable label-the-diagram worksheets | Pictures captured from the 3D model with one structure in pink (several views are tried until it is visible), optional word bank, name/date/score lines and an answer-key page; open to print or download. | Browser test (6+ pictures, key, size) and a visual check. | Some small inner structures are framed very tightly. Landmark-dot worksheets are not offered because the dots are drawn outside the 3D canvas. |

Fixes found on the way: the 3D viewer ignored later changes to which structures it should show (it only read them at start); it now responds. Point-to-part pictures, flashcards and worksheets frame the target tightly with neighbours of similar size.
